## Pour les passionnés de sécurité 🤓☝️
* ASS est en fait construit avec du .NET et du WPF purs, et ne repose que sur votre propre installation de FFMPEG, un outil fiable et standard de l'industrie.
* Oui, Microsoft SmartScreen affichera un avertissement. C'est parfaitement normal, puisque je ne paierai pas des centaines de dollars pour un certificat de signature de code.
* ASS est entièrement **open source** : aucune [porte dérobée](https://storage.googleapis.com/adg-default-storage/Other/iau72yug97d91.webp) 😏, aucune surprise cachée, aucune dépendance douteuse.
* Ne nécessite pas de permissions élevées pour s'exécuter.
* Pas encore convaincu? Examinez le code, modifiez-le ou compilez-le vous-même. Soyez un « utilisateur d'ASS averti »! 🧐
